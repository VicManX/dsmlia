# Ayuda

Esta carpeta reúne procedimientos breves para trabajar con el repositorio. Los
documentos están pensados para consultarse y ejecutarse paso a paso.

## Guías disponibles

1. [Publicar el repositorio en GitHub](01_github_remote_setup.md):
   autenticación, creación del repositorio remoto y primer `push`.
2. [Flujo semanal con Git](02_weekly_git_workflow.md): branches, commits, pull
   requests, merges y tags para las sesiones del curso.

## Convenciones

- Los nombres de archivos y carpetas se escriben en inglés.
- El contenido de las guías se mantiene en español.
- Los comandos se ejecutan desde la raíz del repositorio, salvo que se indique
  lo contrario.
- Cada guía debe explicar cómo verificar el resultado de los pasos realizados.
- Las credenciales, tokens y llaves privadas nunca se almacenan en el
  repositorio.
