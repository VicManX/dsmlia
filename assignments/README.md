# Tareas

Cada entrega tiene una carpeta independiente, aunque haya sido asignada en una
semana concreta:

```text
assignments/assignment_01_name/
├── README.md
├── main.ipynb
└── figures/
```

Esta es la estructura inicial para una tarea pequeña: el desarrollo completo
se mantiene en `main.ipynb` y las gráficas exportadas se guardan en `figures/`.

Para iniciar una entrega, copiar `_template/`, renombrar la copia como
`assignment_XX_name/` y completar su `README.md`. Las carpetas `notebooks/`,
`src/` o `results/` solo se agregan si la complejidad de la tarea lo requiere.
